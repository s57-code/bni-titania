# BNI Titania

- `index.html` — página pública de inscripción a la reunión de los miércoles.
- `panel/` — panel privado del grupo. Pide email y contraseña; los datos los sirve un escenario de Make que valida cada acceso contra la tabla **Accesos** de Airtable. Este repositorio no contiene datos ni claves.

Para dar o quitar acceso: tabla Accesos en Airtable (campo Activo).
